Galeria de Figuras & Fórmulas Geométricas

Explore conceitos fundamentais da geometria plana com 10 formas estilizadas via Tailwind CSS e suas respectivas fórmulas matemáticas.

Quadrado

Quadrado

Polígono regular de 4 lados iguais e 4 ângulos retos de 90°.

Fórmulas (Lado = l):

Área: A = l²

Perímetro: P = 4 · l

Círculo

Círculo

Figura geométrica plana formada por pontos equidistantes do seu centro.

Fórmulas (Raio = r):

Área: A = π · r²

Circunferência: C = 2 · π · r

Retângulo

Retângulo

Quadrilátero com lados opostos paralelos e iguais, possuindo 4 ângulos retos.

Fórmulas (Base = b, Altura = h):

Área: A = b · h

Perímetro: P = 2b + 2h

Elipse

Elipse

Figura curva fechada com dois eixos: semi-eixo maior (a) e semi-eixo menor (b).

Fórmulas (Semi-eixos = a, b):

Área: A = π · a · b

Perímetro: P ≈ π · [3(a+b) - √((3a+b)(a+3b))]

Losango

Losango

Polígono com 4 lados de igual comprimento e diagonais perpendiculares.

Fórmulas (Diagonais = D, d / Lado = l):

Área: A = (D · d) / 2

Perímetro: P = 4 · l

Triângulo

Polígono de 3 lados e 3 ângulos. Sua soma de ângulos internos é 180°.

Fórmulas (Base = b, Altura = h):

Área: A = (b · h) / 2

Perímetro: P = a + b + c

Trapézio

Trapézio

Quadrilátero com dois lados paralelos chamados de base maior (B) e base menor (b).

Fórmulas (Bases = B, b / Altura = h):

Área: A = ((B + b) · h) / 2

Perímetro: P = L1 + L2 + L3 + L4

Paralelogramo

Paralelogramo

Quadrilátero com lados opostos paralelos e iguais em comprimento.

Fórmulas (Base = b, Altura = h):

Área: A = b · h

Perímetro: P = 2a + 2b

Pentágono

Pentágono

Polígono regular de 5 lados de comprimentos iguais e 5 ângulos internos de 108°.

Fórmulas (Lado = l, Apótema = a):

Área: A = (5/2) · l · a

Perímetro: P = 5 · l

Hexágono

Hexágono

Polígono de 6 lados de comprimentos iguais. Pode ser dividido em 6 triângulos equiláteros.

Fórmulas (Lado = l):

Área: A = (3√3 / 2) · l²

Perímetro: P = 6 · l
